FREE GITHUB PAGES

무료 수집·게시 방법

이 사이트는 GitHub Pages에 저장된 assets/deals.json을 표시합니다. PC나 GitHub Actions에서 공개 페이지를 수집하고 JSON을 게시합니다. Cloudflare는 사용하지 않습니다.

내 PC로 관리하기
  1. 프로젝트를 Git으로 내려받아 내 PC에 보관
  2. 수집하고-게시.cmd 파일 실행 (Windows)
  3. 공개 행사 페이지 수집 → assets/deals.json 저장 → GitHub push
  4. Actions가 Pages를 갱신하면 이 페이지에서 ‘게시 데이터 새로고침’ 클릭
GitHub에서 직접 수집 (선택)
  1. GitHub Repository → Actions → Collect Deals
  2. Run workflow → Run workflow 클릭
  3. Actions 완료 후 이 사이트에서 데이터 새로고침

웹페이지에서 바로 PC 프로그램을 실행할 수는 없습니다. 자동 판매처 수집과 개인 링크 저장은 서로 다른 기능입니다.
